## About Me

A 3rd year Cyber Physical Systems Engineering student interested in **AI/ML, quantitative research, software engineering, and game development**. I work with **Python, C++, C#, SQL, Embedded C, and Assembly**, and have applied these languages and tools to machine learning, data-driven systems, embedded development, and interactive software. My interests include **systematic trading, financial markets, algorithmic systems, and XR/game development**, with an emphasis on practical engineering, experimentation, and evidence-based iteration.
